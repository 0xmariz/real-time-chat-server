🖥️ Raw TCP Chat Server Guide

Your server runs a true multi-client TCP socket server on port 8888. Connect from any terminal!

# 1. Connect via Netcat or Telnet: nc localhost 8888 # OR telnet localhost 8888 # 2. Or connect via PowerShell: $client = New-Object System.Net.Sockets.TcpClient("localhost", 8888) $stream = $client.GetStream() $writer = New-Object System.IO.StreamWriter($stream) $reader = New-Object System.IO.StreamReader($stream) $writer.WriteLine("/nick TerminalUser") $writer.Flush() $reader.ReadLine()
Supported TCP Commands:
/nick <name> • /msg <text> • /join <room> • /whisper <user> <text> • /leaderboard • /stories • /stats • /quit
